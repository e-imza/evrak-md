# Üçüncü taraf bileşenler

Projenin MIT lisansı aşağıdaki bağımlılıkların lisanslarını değiştirmez. Dağıtımda ilgili paketlerin kendi LICENSE dosyaları geçerlidir; tam sürümler `package-lock.json` içindedir.

| Bileşen | İşlev | Proje |
|---|---|---|
| PDF.js | PDF metni ve sayfa çizimi | https://github.com/mozilla/pdf.js |
| @napi-rs/canvas | Yerel Canvas çizimi | https://github.com/Brooooooklyn/canvas |
| Sharp / libvips | Görsel normalleştirme | https://sharp.pixelplumbing.com/ |
| Tesseract.js / Tesseract | Yerel OCR motoru | https://github.com/naptha/tesseract.js |
| @tesseract.js-data/tur, eng | Kurulumla gelen OCR modelleri | https://github.com/naptha/tessdata |
| Mammoth | DOCX yapısal dönüşümü | https://github.com/mwilliamson/mammoth.js |
| Turndown / GFM eklentisi | HTML'den Markdown'a | https://github.com/mixmark-io/turndown |
| fast-xml-parser | UDF XML okuma | https://github.com/NaturalIntelligence/fast-xml-parser |
| yauzl | Sınırlı ZIP okuma | https://github.com/thejoshwolfe/yauzl |
| yazl / PDFKit | Yalnızca sentetik test belgesi üretimi | https://github.com/thejoshwolfe/yazl / https://github.com/foliojs/pdfkit |

UDF alan adlarını anlamak için UDF-Toolkit ve udfpdf belgeleri incelendi; proje kaynak kodları veya kişisel veri içeren örnek evrakları buraya kopyalanmadı. Araç UYAP ile bağlantı kurmaz.
